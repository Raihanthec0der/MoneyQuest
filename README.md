# 💰 MoneyQuest

A fun gamified money-saving tracker for teenagers.

MoneyQuest helps users:

- 🌱 Build saving habits
- 🏅 Unlock badges
- 🎖️ Level up
- 🎯 Track financial goals
- 🌳 Grow a Money Tree
- 💯 Earn a Money Score
- 🚀 Stay motivated

## Features

### 📊 Saving Progress
Visual progress bars show saving performance.

### 🏅 Badge System
Unlock achievements such as:

- 🌱 First Step
- 🥉 First 100 Club
- 🥈 First 500 Club
- 🥇 1000 Tk Saver
- ⭐ Smart Saver
- 🚀 Future Investor
- 👑 Money Master
- 💎 Savings Legend

### 🌳 Money Tree
Watch your tree grow as your savings improve.

### 🎯 Goal Tracker
Track progress toward your dream purchase.

### 💯 Money Score
Compete with friends and improve your rank.

## Installation

Clone the repository:

```bash
git clone https://github.com/yourusername/MoneyQuest.git
cd MoneyQuest
```

Run the program:

```bash
python money_quest.py
```
